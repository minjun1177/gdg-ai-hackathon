BugReel — System Architecture & Verification Loop

Reporters send a video. Developers just approve. Powered by gemini-4-argon & antigravity-preview-09-2026.

Reporter Upload UI GitHub Repo Sample PR #1
0. Reporter Video Upload (POST /api/reports) Cloud Run Express

Non-developer uploads a screen recording (.mp4 / .webm / .mov, ≤ 50 MB) + one-line note + target GitHub repo URL. Starts background pipeline and streams live SSE events.

↓ Gemini Files API + Interactions API ↓
[A] Multimodal Video Analysis gemini-4-argon

Pinpoints exact bug_timestamp (e.g. "0:07"), extracts chronological UI steps (type, click, press), and contrasts expected vs. actual state.

↓ AnalysisResult JSON ↓
[B] Managed Agent Call #1 — Reproduce (RED Gate) Must Fail First

antigravity-preview-09-2026 clones repo in remote sandbox, serves app on :4173, writes tests/repro.spec.js, and runs Playwright + verify.py. Stops at not_reproduced if test passes.

↓ Confirmed Failing Test (RED: passed < total) ↓
[C] Managed Agent Call #2 — Fix Loop (GREEN Gate) Verified Fix

Patches application code (never weakening tests), loops Playwright + verify.py up to 5 attempts until passed === total, and pushes branch bugreel/fix-<id>.

↓ FixResult JSON + Server-Side Test Guard ↓
[D] Developer Review & Human Approval Gate Human-in-the-Loop

Developer inspects timeline marker, RED → GREEN test counter, and unified diff on /review/:id. Clicking Approve & Open PR calls GitHub REST API to open the Pull Request.
